# Tokyo Ghoul Fanpage

This project is a simple static fanpage dedicated to the manga *Tokyo Ghoul* by Sui Ishida. It replaces the previous calculator example with a small website built using plain HTML, CSS and JavaScript.

## Features

- Navigation between Home, Characters and Gallery sections
- Characters rendered dynamically with JavaScript
- Responsive layout using basic CSS

## Usage

Open `index.html` in any modern web browser.

## Disclaimer

This is an unofficial fan project and is not affiliated with the creators or publishers of Tokyo Ghoul.
