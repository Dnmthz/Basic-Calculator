# Tokyo Ghoul Fanpage

A polished static fan site dedicated to the manga *Tokyo Ghoul* by Sui Ishida. The page features character cards with images, a responsive gallery, and a dark themed design.

## Features

- Hero banner with cover art and navigation
- Characters rendered dynamically with images and descriptions
- Gallery of manga covers
- Responsive layout built with plain HTML, CSS, and JavaScript

## Usage

Serve the files locally and open the site in a browser:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
